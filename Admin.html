Aksi Cepat

Generate token untuk semua peserta yang belum punya token, atau tambah data baru.

Cara Pakai Cepat

  1. Pastikan setup spreadsheet sudah dijalankan (menu Ujian Online → 1. Setup Spreadsheet di Spreadsheet).
  2. Tambah data peserta di tab Peserta (atau import dari CSV).
  3. Tambah soal pilihan ganda di tab Soal.
  4. Buka tab Token → klik Generate Token Massal untuk membuat token unik per peserta.
  5. Distribusikan token + password ke masing-masing peserta (cetak kartu atau kirim manual).
  6. Peserta login di halaman utama dengan username + password + token.
  7. Pantau progress di tab Hasil dan pelanggaran di tab Log Pelanggaran.

Manajemen Token

Cara kerja token (one-time link): Setiap peserta mendapat token unik. Saat peserta pertama kali login dengan token + password yang benar, status berubah menjadi in_progress dan token tidak bisa dipakai untuk sesi lain. Setelah submit, status menjadi completed.
