Petunjuk:
1. Pastikan Anda menggunakan browser terbaru (Chrome / Edge / Firefox).
2. Token bersifat satu kali pakai - sekali login, token tidak dapat digunakan lagi untuk sesi lain.
3. Setelah klik "Mulai Ujian", layar akan masuk mode fullscreen otomatis.
4. Keluar dari tab, menutup fullscreen, atau copy-paste akan dicatat sebagai pelanggaran. 3 pelanggaran = ujian auto-submit.
